# Cloud leg

What the hybrid adds to the client's account: a frontier model path and a backup target. Nothing
else. The documents, the vector store, and the interface stay on the office box, which is the
whole point of the hybrid.

The KMS key belongs to the client and they hold it, so an offsite backup is not a disclosure.
Our access is a scoped role they can revoke, and every use of it is logged in their account.
